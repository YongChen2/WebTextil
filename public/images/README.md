# Obrázky webu

Nahrajte sem fotky ve formátu WebP s přesně těmito názvy. Chybějící soubor se na webu
zobrazí jako šedá plocha (#E5E2DD) s názvem souboru. Po nahrání je potřeba nový build/deploy.

| Soubor | Kde | Doporučený poměr |
| --- | --- | --- |
| sluzba-trika.webp | Služby – Potisk triček | 4:5 (např. 1600×2000) |
| sluzba-nasivky.webp | Služby – Našívky | 4:5 |
| sluzba-saka.webp | Služby – Úpravy sak | 4:5 |
| galerie-01.webp … galerie-09.webp | Galerie (kategorie viz `src/data/content.ts`) | 1:1 (např. 1200×1200) |
| o-nas.webp | O nás – foto týmu | 4:5 |

Alt texty (popisy pro nevidomé a vyhledávače) upravíte v `src/data/content.ts`.
